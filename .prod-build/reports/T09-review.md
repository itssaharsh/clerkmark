## Security checklist (one line per item)

- **Secrets:** `git log -p` was grepped for `sk-ant`, key and token patterns (`sk-ant-…`, `ghp_`, `AKIA`, `Bearer …`, `TOKEN=`/`KEY=` with a value). Nothing real turned up, only env var names and brief text. `.env.example` has empty placeholders only. `web/` has no `process.env`, API key or token. The CourtListener token is used only in a server-side header (courtlistener.py:268) and is never echoed. `.env` is gitignored.
- **Client exposure:** app.js renders every filing-derived string through `el()`/`textContent`/`createTextNode` (app.js:178–195; no `innerHTML`, `insertAdjacentHTML`, `eval` or `new Function`). Drawer links are server-built CAP URLs with `rel=noopener`. The payload `<img src=x onerror=alert(1)>` round-trips as literal JSON text in the quote and in the upload's file name (`test_xss_payload_round_trips_as_plain_json_text`). The Playwright check `tests/browser/xss_no_dialog.mjs` puts the payload into every printed field of the sample memo, and separately uploads a file named with the payload. Result: no dialog, no `<img src=x>` in the DOM, the payload visible as text, 0 CSP violations (**E0006**). Filings also go through eyecite, which drops an HTML party name before it reaches `plaintiff`.
- **Validation:** the live server gives non-PDF bytes 415, an empty body or blank text 400, more than 4 MB 413 (with or without Content-Length; chunked is fixed, item 4) and more than 200k characters 413. `/static/../main.py`, `/static/%2e%2e/main.py`, `..%2f`, `..%5c` and `%2e%2e/%2e%2e/etc/passwd` all get 404, both on the wire (`curl --path-as-is`) and as raw ASGI paths in tests. Sample ids `../../etc/passwd`, `%2e%2e`, `..%2f..%2fetc%2fpasswd` and `sample-motion%00` get a 404 `not_found`. The id is only matched against seed/samples.json (memo.py `sample_record`), and a test proves `run_sample` is never reached (E0012, E0008).
- **Limits:** 11 rapid requests from one address give 10×200 then 429 with the exact `rate_limited` envelope (live, E0012). 5 simultaneous sample runs all return 200 with identical classes and distinct run_ids. A 60-page text with 260 full citations to cached volumes finishes offline with 250 rows and a "Truncated:" line, inside the 60 s wall-clock assertion (`time.time`, F-0003) (E0008).
- **Dependencies:** `uvx pip-audit -r requirements.txt` ran in an isolated env, because the venv has no pip and was not modified. Result: "No known vulnerabilities found" (**E0009**). All 13 requirements are pinned with `==`. The Node devDependencies (playwright, @axe-core/playwright, caret ranges) are QA-only and not deployed.
- **Never-red promise:** the whole-volume invariant tests (`test_every_real_case_at_its_own_page_is_never_red`, `test_real_case_wrong_page_is_never_red`) pass. The adversarial cases added are: every cached case cited in Bluebook form; ten brief-form real cases through the whole pipeline (including a real case cited with the wrong court and year, `Greenleaf … (9th Cir. 2001)`, which verifies); a string cite of eight cases, which verifies seven and keeps Miller red. All were red before the fix (items 1 and 2) and none are red now. The residual is item 10.
- **Logging:** the per-run JSON line holds run_id, the input's sha256, the file name's sha256, counts, timings, sources and offline. It has no filing text and no file name (item 3). CAP warnings log URLs only. `_unhandled` logs the exception, not the body.
- **Failure paths:** if the corpus dies mid-run (case files fail after the volume lookups), the memo is 200 with a warning, quotes are marked not_checked and the same 3 rows are red. Malformed CAP JSON (non-JSON or the wrong shape) gives a `not_checked` "unreadable reply" row, no 500 and nothing cached (item 6). If the advisory client raises, every `advisory` is None and the classes are unchanged. The existing AC-6 tests (a whole volume or index failing) still pass.
- **Wording:** an AST scan of every string literal in citememo/*.py and main.py (docstrings excluded) found "fabricated" only inside `likely_fabricated` and `real_cases_marked_fabricated`. `LABELS["likely_fabricated"] == "Likely not a real case."`. No row label, reason or tally on the sample memo contains "fabricat". In app.js, "fabricated" appears only as the key `real_cases_marked_fabricated` (app.js:1328). UI-SPEC §9 strings were not touched.

## CONCERNS for the UI lane (web/, qa/; not changed here)

- The page is now served with a CSP (main.py `CONTENT_SECURITY_POLICY`). This breaks if anyone adds an inline `<script>`, an `on*=` attribute, `eval`, a cross-origin `fetch`, or a font or style host other than Google Fonts. The fix in that case is to update the policy in main.py. `qa.mjs --static` does not send the header, so only runs against uvicorn exercise it. `tests/browser/xss_no_dialog.mjs <url>` checks it on the current page.
- No XSS finding in app.js. Keep the `el()`/textContent rule: `tests/browser/xss_no_dialog.mjs` fails if any memo field is ever rendered as markup.
