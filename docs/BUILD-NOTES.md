# BUILD NOTES — Court-intake citation memo (working repo name: cite-intake)

Read this before touching code. Facts below were verified on 2026-09-26 with real requests. Product name and visual identity come from `docs/UI-SPEC.md` once written; until then use the working name.

## 0. What we are building (one paragraph)
Court intake staff (clerk's office / self-help centre / pro se staff attorney) drop a self-represented litigant's filed PDF. The app extracts every case citation, resolves each against a FREE case-law corpus (Caselaw Access Project static files; CourtListener as an optional second source when a token is configured), matches quoted passages against the opinion text, and produces a one-page memo that sorts each citation into a class with the RULE THAT FIRED printed under the row. The headline contrast: a fabricated citation ("925 F.3d 1339" lands inside a different real case) versus a real citation the free corpus simply doesn't hold (e.g., a 2023 U.S. Reports cite beyond CAP's coverage) — a naive checker gives both the same "not found". The memo is a triage aid, never a finding; the wording must never call a citation "fabricated" as a fact — the class is "likely fabricated" with its evidence.

## 1. Verified facts about data sources (2026-09-26)
- **CourtListener v4 citation-lookup API** (`POST https://www.courtlistener.com/api/rest/v4/citation-lookup/`, form field `text`) returns **HTTP 401 without a token** ("Authentication credentials were not provided."). With a token: throttled to 60 valid citations/minute, ≤250 citations per request, ≤64,000 chars; per-citation statuses 200 found / 300 ambiguous / 404 "valid, but we were unable to look it up" / 400 invalid reporter / 429 throttled. New accounts (post 2026-05-07) have an unstated default rate limit. → **Optional** source: env `COURTLISTENER_TOKEN`; header `Authorization: Token <token>`. Cache every response.
- **Caselaw Access Project (CAP) static files, no auth, CORS-irrelevant (server-side fetch):**
  - `https://static.case.law/ReportersMetadata.json` → 401 reporters: `{id, full_name, short_name, start_year, end_year, jurisdictions, harvard_hollis_id, slug}`. Cached copy: `data/cap/ReportersMetadata.json`. Examples: `f3d` (F.3d, 1990–2019), `f-supp-3d` (1968–2019 label; series actually starts 2014), `f-supp-2d`, `us` (U.S., 1754–2014), `cal-rptr-3d` (2012–2019), `ny3d` (2003–2017).
  - `https://static.case.law/{slug}/VolumesMetadata.json` → per volume `{volume_number (string), start_year, end_year, spine_start_year, spine_end_year, reporter_slug, redacted, ...}`. F.3d: volumes 1–935 (cached copy `data/cap/f3d.VolumesMetadata.json`); U.S.: max volume 572; F. Supp. 2d: max 999; Cal. Rptr. 3d: 196–251 only.
  - `https://static.case.law/{slug}/{volume}/CasesMetadata.json` → list of `{id, name, name_abbreviation, decision_date, docket_number, first_page, last_page (strings), citations:[{type, cite}], court:{name,...}, jurisdiction, file_name, ...}`.
  - `https://static.case.law/{slug}/{volume}/cases/{file_name}.json` → full case: `casebody.opinions[].text` (plain text, **no star pagination**, so pin cites cannot be verified from CAP), `casebody.head_matter`, `name_abbreviation`, `decision_date`, `court.name`, `citations`.
  - Mapping eyecite reporter → CAP slug: match `short_name` from ReportersMetadata (e.g. "F.3d" → `f3d`, "F. Supp. 2d" → `f-supp-2d`, "U.S." → `us`, "Cal. Rptr. 3d" → `cal-rptr-3d`). Build a dict at startup from the cached ReportersMetadata; fall back to slugifying.
  - Verified lookups: `925 F.3d 1339` → inside **J.D. v. Azar**, 925 F.3d 1291–1349 (D.C. Cir. 2019-06-14), file `1291-01`, opinion text 179,251 chars. `905 F. Supp. 2d 121` → **United States v. ISS Marine Services, Inc.** 121–142 (2012-11-21). `174 F.3d 366` → inside **Greenleaf v. Garlock, Inc.** 352–368 (1999-04-26). `516 U.S. 217` → **Zicherman ex rel. Estate of Kole v. Korean Air Lines Co.** 217–232 (1996-01-16), file `0217-01`. Volume 925 F.3d spine years 2016–2019 (CAP's per-volume years are loose: use ±1 year tolerance and prefer decision_date of the matched case).
- **eyecite 2.7.8** (`from eyecite import get_citations, clean_text`): `FullCaseCitation` with `.groups['volume'|'reporter'|'page']`, `.metadata.pin_cite|year|court|plaintiff|defendant`, `.span()` for character offsets, `.matched_text()`. `Id.`/`supra`/short-form cites are separate classes (`IdCitation`, `SupraCitation`, `ShortCaseCitation`) → list as *skipped*. Unknown reporters ("123 Fake.Rptr. 456") are **silently dropped** → add a regex catch `\b(\d{1,4})\s+([A-Z][A-Za-z.\s']{1,25}?)\s+(\d{1,5})\b` on text spans not covered by eyecite spans, class `unrecognized_reporter`. WL / LEXIS cites (`2019 WL 4639462`) are not in any free corpus → class `not_in_free_corpus` with note "Westlaw-only citation".
- **reporters_db** (`from reporters_db import REPORTERS`): edition date ranges (F. 1880–1924, F.2d 1924–1993, F.3d 1993–, F.4th 2021–). Use for "year inconsistent with edition" and "reporter unknown" checks.
- **Toolchain present:** Python 3.12 venv at `.venv` with deps in `requirements.txt` (eyecite, pdfplumber, rapidfuzz, fastapi, uvicorn, httpx, python-multipart, pydantic, fpdf2, pytest, anthropic). Node 22 with `playwright` + `@axe-core/playwright` installed in `node_modules`; Chromium launches headless. No Docker. Vercel CLI not installed (user deploys). `gh` present.

## 2. Architecture (decided; verify, don't redesign)
- One Python service: **FastAPI** app in `main.py` (module-level `app`), serving the static front end from `web/` at `/` and JSON at `/api/*`. Runs locally with `uvicorn main:app --reload`. Deployable to Vercel (Python runtime; `vercel.json` with a rewrite of everything to `main.py` OR Vercel's zero-config FastAPI detection — the build agent for deploy decides and documents) and anywhere via `Procfile`/`start.sh`.
- Package `citememo/`:
  - `models.py` — pydantic models: `Citation`, `CitationResult` (class, reasons[], evidence{}, source, quote_check), `Memo` (filing metadata, results[], counts, timings, sources_used[]).
  - `extract.py` — pdf → text (pdfplumber; fail with a clear error when no text layer), eyecite extraction, quote attachment (a quoted string of ≥ 25 chars within 400 chars before the citation, or after a "quoting"), pin-cite capture, skipped-cite listing, unrecognized-reporter regex.
  - `cap.py` — CAP client with an on-disk JSON cache (`seed/cache/cap/...`) and a small in-memory LRU; functions: `reporter_slug(short_name)`, `volumes(slug)`, `cases_in_volume(slug, vol)`, `case_json(slug, vol, file_name)`, `find_case_at_page(slug, vol, page)`, `find_case_by_name(slug, vol, plaintiff, defendant)`. Timeouts 20 s, retries 1, User-Agent set. All network calls go through here so the replay mode can serve from cache only (`CITEMEMO_OFFLINE=1`).
  - `courtlistener.py` — optional; `lookup(text)` when `COURTLISTENER_TOKEN` set; maps statuses; never required for the golden path.
  - `rules.py` — the deterministic classifier (see §3). Pure functions, unit-tested, no I/O (takes already-fetched metadata).
  - `quotes.py` — rapidfuzz `partial_ratio` of each quoted passage against the opinion text (normalize whitespace/quotes); threshold: ≥ 92 verified, 70–91 "closest passage N%" (quote_not_found_verbatim), < 70 quote_not_found. Return the best-matching window (±200 chars) as evidence.
  - `advisory.py` — optional LLM "does the cited passage support the stated proposition?" per verified citation with a quote/proposition; Anthropic API via env `ANTHROPIC_API_KEY`, model `claude-haiku-4-5-20251001` (cheap/fast) — one call per citation, JSON output {verdict: supports|does_not_support|cannot_tell, why}. Off when the key is absent: column shows "not run". Labelled ADVISORY everywhere.
  - `memo.py` — orchestrates: extract → group by reporter/volume → fetch metadata (concurrently, bounded to 6) → classify → quotes → advisory → Memo; records per-stage timings and the sources used.
- API: `POST /api/memo` (multipart `file` PDF or form `text`) → `Memo` JSON; `GET /api/samples` → list of seeded samples; `POST /api/memo/sample/{id}` → runs the seeded sample (live unless offline, then cache); `GET /api/eval` → the seeded 20-citation evaluation (ground truth vs predicted, per-class counts, false-positive count, latencies) computed from the last run of the seed or on demand; `GET /api/health`.
- Front end `web/`: plain HTML + CSS + vanilla JS (no framework). One page: upload/drop zone + 2–3 one-click samples → the memo (the hero object is the memo table drawn over the citations) → tabs/sections: Memo · Evidence per row (expandable: the rule that fired, the real case at that page, the closest passage) · Eval · How it works. `?state=first-run|loading|partial|error|no-results` renders each state; `?demo=1` preloads the seed; Alt+Shift+R resets; Alt+Shift+P switches to the recorded replay (`seed/replay.json`, labelled "Replay · run of <date>"). Export memo as PDF via browser print stylesheet (`@media print`), no server PDF.
- Seed (`seed/`): `sample-motion.txt` (source) → `sample-motion.pdf` (generated by `scripts/make_seed_pdf.py` with fpdf2), `ground_truth.json` (20 citations with expected class), `cache/` (CAP JSON for every citation in the seed so offline replay works), `replay.json` (a recorded real run, produced by `scripts/record_replay.py`).
- Tests (`tests/`): pytest for `rules.py` (every class, edge cases), `extract.py` (quote attachment, skipped cites, unrecognized reporter), `quotes.py`; an integration test that runs the seed from cache and asserts the ground truth (≥ 18/20 correct, 0 real cases labelled likely_fabricated).
- Scripts: `scripts/make_seed_pdf.py`, `scripts/warm_cache.py` (fetch CAP JSON for the seed), `scripts/record_replay.py`, `scripts/eval.py` (prints the eval table), `qa/qa.mjs` (Playwright screenshots at 320/390/1024/1440 × states + axe).

## 3. The decision rule (deterministic; the product's core claim)
Input per full citation: volume V, reporter R (eyecite normalized), page P, pin cite (optional), year Y (optional), court (optional), plaintiff/defendant (optional), quoted passages (optional).
1. **R unknown** to reporters_db AND to CAP ReportersMetadata → `unrecognized_reporter` (reason: "no reporter called R"). Shown in the fabricated register but worded "unrecognized reporter".
2. **Westlaw/Lexis-only cite** (`WL`, `LEXIS`, `U.S. Dist. LEXIS`, slip ops) → `not_in_free_corpus` (reason: "proprietary citation; not checkable in a free corpus").
3. **Edition/year consistency** (reporters_db): if Y is given and outside the edition's [start−1, end+1] → `likely_fabricated` (reason: "R did not publish in Y (edition runs start–end)").
4. **Volume range**: CAP `VolumesMetadata` for R's slug. Let Vmax = max volume present. If V > Vmax: estimate volumes/year from the last 10 CAP volumes' years; if V exceeds Vmax + (yearsSinceCapEnd + 2) × rate × 1.5 → `likely_fabricated` ("volume V does not exist yet: R reached Vmax by CAP's end year; ~N volumes/year"); else → **beyond free coverage**: if CourtListener configured and returns 200 → treat as found (source CL; quote check only if CL text fetched — v1: skip text) else `not_in_free_corpus` ("R volumes after Vmax are not in the free corpus; check CourtListener/Westlaw"). If V ≤ Vmax but the volume is missing from CAP → `not_in_free_corpus` ("volume missing from the free corpus").
5. **Volume present**: load CasesMetadata. If P > max(last_page) → `likely_fabricated` ("volume V ends at page N"). If Y given and outside [vol.start_year−1, vol.end_year+1] → `likely_fabricated` ("volume V covers years A–B").
6. **Case at page**: find case with first_page ≤ P ≤ last_page.
   - No case at P (gap pages / head matter) → try name search (step 7); if no name hit → `likely_fabricated` ("no case begins at or spans page P").
   - Case found and `first_page == P` and names match (fuzzy: token_set_ratio ≥ 80 on plaintiff vs first party OR defendant vs second party; if eyecite has no party names, accept) → `verified` (then quote check → may become `quote_not_found`).
   - Case found but `first_page != P` (P is inside another case) → name check: if the names match the spanning case → `wrong_page` ("P is a pin page of X, which begins at first_page") (class: `wrong_cite_exists`); else name search in volume (step 7).
   - Case found at first_page == P but names don't match → step 7.
7. **Name search in volume**: fuzzy match plaintiff/defendant against every `name_abbreviation` in the volume. Hit → `wrong_cite_exists` ("X exists at V R first_page, not P"). No hit → `likely_fabricated` ("page P belongs to <real case> (first_page–last_page); no case named <plaintiff> in volume V"). With a CourtListener token, also run a case-name search across the corpus before concluding (v2; document as future work if not built).
8. **Quote check** (verified only): see quotes.py. Pin cites: CAP has no pagination → `pincite_unverified: true` (note, not a class).
9. **Advisory** (verified only, when key present): supports / does_not_support / cannot_tell. Never changes the class.
Classes (final): `verified`, `quote_not_found`, `wrong_cite_exists`, `not_in_free_corpus`, `unrecognized_reporter`, `likely_fabricated`, plus `skipped` (Id./supra/short/statute). Every result carries `reasons: [str]` (human sentences), `evidence: {real_case_at_page?, volume_range?, edition_range?, closest_passage?, similarity?}`, `source: "CAP"|"CourtListener"|"none"`, `links: [CAP static URL(s) used]`.

## 5. Rules and honesty constraints
- Every number on screen comes from the run or the seed. Sample content is labelled on the content ("synthetic sample filing"). No invented users, quotes, testimonials or logos.
- The memo header: "Triage aid. Not a finding. Verify flagged rows before relying on them." Classes are worded as observations ("page 1339 belongs to J.D. v. Azar") not verdicts.
